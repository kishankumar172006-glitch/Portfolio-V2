# Personal Portfolio Website

My personal portfolio website built using HTML and CSS.

## About

This website introduces me and showcases my interests, education, skills, and important links. I created it as part of my journey in learning web development.

## Built With

- HTML5
- CSS3

## Features

- About Me section
- Interests and hobbies
- Education details
- Skills section
- Important links
- Contact form layout
- Technology-inspired background
- Responsive design for laptop and mobile screens

## Project Structure

```text
portfolio/
├── index.html
├── style.css
├── README.md
└── photo/
    └── image 3.png
```

## How to Run

1. Open the project folder in VS Code.
2. Open `index.html`.
3. Run it in your browser, or use the Live Server extension.
4. Edit `style.css` to customize the website's appearance.

## What I Learned

- HTML page structure
- CSS selectors and styling
- Flexbox
- Background images and colors
- Responsive design using media queries
